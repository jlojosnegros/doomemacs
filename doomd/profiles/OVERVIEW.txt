🚀 Comandos Rápidos
─────────────────────────────────────────────────────────────────────────

  Lanzar perfil:
    $ emacs --profile python
    $ emacs --profile cpp
    $ emacs --profile rust

  Sincronizar:
    $ doom sync --profile python
    $ doom sync --profile cpp
    $ doom sync --profile rust

  Con el script:
    $ ~/.doom.d/profiles/switch-profile.sh launch python
    $ ~/.doom.d/profiles/switch-profile.sh sync
    $ ~/.doom.d/profiles/switch-profile.sh list

⌨️  Keybindings Principales
─────────────────────────────────────────────────────────────────────────

  GLOBAL (sin evil-mode):
    C-x C-f       Abrir archivo
    C-x C-s       Guardar
    C-c p f       Buscar archivo en proyecto
    C-c p p       Cambiar proyecto
    C-c C-,       Abrir config

  LOCALLEADER (C-c m):
    C++ →    c = compile, r = recompile, f = format
    Python → ' = REPL, t t = pytest, f = format
    Rust →   c b = build, c r = run, c t = test


🎯 Próximos Pasos
─────────────────────────────────────────────────────────────────────────

  1. Lee QUICKSTART.md para empezar
  2. Instala las dependencias del sistema (clangd, pyright, rust-analyzer)
  3. Sincroniza todos los perfiles: ~/.doom.d/profiles/switch-profile.sh sync
  4. Prueba cada perfil: emacs --profile <nombre>
  5. Personaliza según tus necesidades
